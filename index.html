Comment ça se joue

Tracez des segments entre les points. À la fin, ils doivent former une seule boucle fermée : pas de branchement, pas de croisement, pas de deuxième boucle dans un coin.

Un chiffre dans une case dit combien de ses quatre côtés sont tracés. Les cases vides ne disent rien. Chaque grille n'a qu'une solution.

Les gestes

  • Tap ou clic sur une arête : trait, puis croix, puis rien.
  • Glisser : trace toute une suite d'arêtes d'un coup.
  • Flèches pour se déplacer, Espace pour tracer, X pour barrer.
  • Ctrl+Z annule, Ctrl+Maj+Z refait.

La croix ne sert à rien pour le jeu : elle sert à vous. C'est le repère au crayon qui dit « pas ici », pour ne pas y revenir.
